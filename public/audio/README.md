# Audios placeholder

Fichiers de test générés (tonalités synthétiques, ~4s, mono 64kbps ≈ 32 Ko
chacun) — **pas du vrai contenu**. Servent uniquement à valider le mécanisme
technique du lecteur audio et du précache offline.

À remplacer par les vrais enregistrements UNICEF/MINPROFF avant la
candidature/le pilote. Garder le même gabarit de poids (mono, bas débit,
quelques dizaines de Ko à quelques centaines de Ko par minute) pour rester
raisonnable sur le précache PWA en contexte data mobile limité.
